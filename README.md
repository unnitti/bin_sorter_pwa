# PB 코드 정렬

클립보드에 있는 `11pb0131001` 형식의 코드를 정렬하고 `pb1-31-001` 형식으로 변환하는 초경량 iPhone용 웹앱입니다.

## 처리 규칙

1. `11`은 고정값으로 봅니다.
2. 다음 영문 2자리를 1차 기준으로 알파벳 순 정렬합니다. (`pb`, `pc`, `pd`, `pi`, `pj`, `ra`, `rb` 등)
3. 영문 2자리가 같으면 뒤 7자리 숫자를 숫자 기준 오름차순 정렬합니다.
4. 뒤 7자리는 `01 / 31 / 001`처럼 나누어 `pb1-31-001` 형식으로 변환합니다. 첫 두 자리는 숫자로 변환하므로 `01`은 `1`, `15`는 `15`가 됩니다.
5. 입력의 공백, 탭, 줄바꿈 등은 항목 구분자로 처리합니다.
6. 형식이 맞지 않는 항목은 결과에서 제외합니다.

앱을 실행하면 클립보드를 자동으로 읽어 처리하고 결과를 화면에 표시한 뒤 다시 클립보드에 복사합니다. iOS/Safari의 클립보드 보안 정책으로 자동 접근이 거부되는 경우에는 `다시 가져오기` 버튼을 사용합니다.

외부 라이브러리, 웹폰트, 이미지 리소스를 사용하지 않습니다.
