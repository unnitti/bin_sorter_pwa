# 지번 정렬

클립보드에 있는 지번을 오름차순 또는 내림차순으로 정렬하고, 업무에서 사용하기 편한 형식으로 변환하는 초경량 iPhone용 웹앱입니다.

**[앱 실행하기](https://unnitti.github.io/bin_sorter_pwa/)**

## 사용 방법

1. 지번을 여러 개 복사합니다.
2. 지번 정렬 웹앱을 엽니다.
3. **클립보드 가져오기** 버튼을 누릅니다.
4. 코드를 정렬하고 형식을 변환합니다.
5. 필요한 줄을 누르면 해당 줄만 클립보드에 복사됩니다.
6. **클립보드에 전체 복사** 버튼을 누르면 현재 정렬된 전체 결과가 클립보드에 복사됩니다.
7. 필요하면 **내림차순** 버튼을 눌러 전체 정렬 순서를 바꿀 수 있습니다.

iPhone/Safari에서는 웹앱이 사용자 동작 없이 클립보드를 읽을 수 없으므로, 앱을 연 뒤 **클립보드 가져오기** 버튼을 눌러야 합니다.

## 입력 형식

앞의 두 자리는 특정 숫자로 고정하지 않고 무시합니다. 현재 다음 형식의 코드만 처리합니다.

```text
숫자 2자리 + 영문 2자리 + 숫자 7자리
```

예:

```text
11PB0131001
12PB1510001
13PC0131002
```

공백, 탭, 줄바꿈 등은 각각 다른 항목으로 처리합니다.

따라서 여러 코드를 줄바꿈하여 복사하거나 한 줄에 공백으로 나열해도 됩니다.

## 정렬 규칙

### 1. 앞 두 자리 숫자는 무시

앞의 두 자리는 `11`, `12`, `13` 등 어떤 두 자리 숫자라도 입력할 수 있으며 정렬과 출력에서는 사용하지 않습니다.

### 2. 영문 2자리를 먼저 정렬

영문 부분을 알파벳 순서로 정렬합니다.

예:

```text
PA
PC
PJ
RB
RD
```

### 3. 같은 영문 코드 안에서는 숫자로 정렬

영문 2자리가 같으면 뒤의 7자리 숫자를 **문자열이 아니라 숫자 값으로** 비교합니다.

기본은 오름차순이며, **내림차순** 버튼을 누르면 영문과 숫자를 포함한 전체 정렬 순서가 역순으로 바뀝니다.

## 결과 형식

뒤의 7자리 숫자를 다음 세 부분으로 나누어 표시합니다.

```text
01 / 31 / 001
```

첫 번째 두 자리는 숫자로 변환하여 표시합니다.

따라서:

```text
12PB0131001
```

은

```text
PB1-31-001
```

형태로 변환됩니다.

영문은 결과에서 대문자로 표시됩니다.

`01`은 `1`로 표시되지만 `15`는 `15`로 표시됩니다.

## 결과 복사

정렬 결과의 각 줄을 누르면 그 줄 하나만 클립보드에 복사됩니다.

하단의 **클립보드에 전체 복사** 버튼을 누르면 현재 화면에 표시된 정렬 순서 그대로 전체 결과가 복사됩니다.

따라서 전체 목록을 한 번에 사용하는 경우와 한 줄씩 사용하는 경우를 모두 지원합니다.

## 잘못된 형식의 입력

입력에 지번 형식에 맞지 않는 항목이 섞여 있어도 전체 작업이 중단되지는 않습니다.

형식에 맞지 않는 항목은 결과에서 제외됩니다.

예를 들어:

```text
11PB0131001
hello
12PC0131002
```

라면 `hello`는 제외하고 지번만 처리합니다.

제외된 항목의 개수는 결과 메시지에서 알려 줍니다.

## 클립보드 접근이 되지 않는 경우

iPhone/Safari의 클립보드 보안 정책에 따라 웹앱은 사용자 동작 없이 클립보드를 읽을 수 없습니다.

앱을 연 뒤 **클립보드 가져오기** 버튼을 눌러 클립보드를 읽어오세요.

## 알아두세요

이 앱은 특정 업무에서 사용하는 지번 형식만을 대상으로 만든 도구입니다.

일반적인 문자열 정렬 프로그램이 아니며, 다음 형식을 전제로 합니다.

```text
숫자 2자리 + 영문 2자리 + 숫자 7자리
```

다른 형식의 코드가 입력되면 결과에서 제외됩니다.

중요한 업무에 사용할 때는 정렬 결과를 한 번 확인한 후 사용하세요.
