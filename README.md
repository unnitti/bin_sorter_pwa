# 지번 정렬

클립보드에 있는 지번을 자동으로 오름차순 정렬하고, 업무에서 사용하기 편한 형식으로 변환하는 초경량 iPhone용 웹앱입니다.

**[앱 실행하기](https://unnitti.github.io/bin_sorter_pwa/)**

## 사용 방법

1. 지번을 여러 개 복사합니다.
2. 지번 정렬 웹앱을 엽니다.
3. 앱이 클립보드를 자동으로 읽습니다.
4. 코드를 정렬하고 형식을 변환합니다.
5. 결과를 화면에 표시합니다.
6. 정렬된 결과를 자동으로 클립보드에 복사합니다.
7. 필요한 곳에 붙여넣습니다.

따라서 정상적으로 클립보드 접근이 허용되는 환경에서는 **앱을 열기만 하면 됩니다.**

## 입력 형식

현재 다음 형식의 코드만 처리합니다.

```text
11 + 영문 2자리 + 숫자 7자리
```

예:

```text
11PB0131001
11PB1510001
11PC0131002
```

공백, 탭, 줄바꿈 등은 각각 다른 항목으로 처리합니다.

따라서 여러 코드를 줄바꿈하여 복사하거나 한 줄에 공백으로 나열해도 됩니다.

## 정렬 규칙

### 1. 앞의 `11`은 고정값

모든 코드의 앞 두 자리 `11`은 무시합니다.

### 2. 영문 2자리를 먼저 정렬

영문 부분을 알파벳 순서로 정렬합니다.

예:

```text
PA
PC
PJ
RB
RD
```

### 3. 같은 영문 코드 안에서는 숫자로 정렬

영문 2자리가 같으면 뒤의 7자리 숫자를 **문자열이 아니라 숫자 값으로** 비교하여 오름차순 정렬합니다.

따라서 예를 들어:

```text
...0100001
...1500001
```

과 같은 경우 숫자 값의 크기에 따라 정렬됩니다.

## 결과 형식

뒤의 7자리 숫자를 다음 세 부분으로 나누어 표시합니다.

```text
01 / 31 / 001
```

첫 번째 두 자리는 숫자로 변환하여 표시합니다.

따라서:

```text
11PB0131001
```

은

```text
PB1-31-001
```

형태로 변환됩니다.

`01`은 `1`로 표시되지만 `15`는 `15`로 표시됩니다.

## 잘못된 형식의 입력

입력에 지번 형식에 맞지 않는 항목이 섞여 있어도 전체 작업이 중단되지는 않습니다.

형식에 맞지 않는 항목은 결과에서 제외됩니다.

예를 들어:

```text
11PB0131001
hello
11PC0131002
```

라면 `hello`는 제외하고 지번만 처리합니다.

제외된 항목의 개수는 결과 메시지에서 알려 줍니다.

## 클립보드 접근이 되지 않는 경우

iPhone/Safari의 클립보드 보안 정책에 따라 앱이 처음 실행될 때 클립보드 접근이 허용되지 않을 수 있습니다.

이 경우 화면의 **다시 가져오기** 버튼을 눌러 다시 시도하세요.

클립보드를 읽을 수 없으면 결과를 만들지 않고 다시 시도할 수 있는 상태로 표시됩니다.

## 결과가 클립보드에 복사되지 않는 경우

지번 정렬 자체와 결과 표시가 정상적으로 이루어졌더라도 브라우저가 클립보드 쓰기를 허용하지 않을 수 있습니다.

이 경우 화면에 표시된 결과를 직접 확인하여 사용할 수 있습니다.

## 알아두세요

이 앱은 특정 업무에서 사용하는 지번 형식만을 대상으로 만든 도구입니다.

일반적인 문자열 정렬 프로그램이 아니며, 다음 형식을 전제로 합니다.

```text
11 + 영문 2자리 + 숫자 7자리
```

다른 형식의 코드가 입력되면 결과에서 제외됩니다.

중요한 업무에 사용할 때는 정렬 결과를 한 번 확인한 후 사용하세요.
